## Summary
SEV3. On 2025-10-09 at 15:20 IST, a configuration deployment to the payment-orchestrator service set the downstream call timeout to 300 milliseconds instead of the intended 3000 milliseconds. Approximately 2,100 customers experienced failed or declined transactions over a 45-minute window before rollback.

## Impact
Transactions requiring a round trip to NorthGate Card Switch (see ARCH-001) began timing out at the orchestrator level even though NorthGate itself was healthy. CrestPay Instant transfers (SPEC-001) and QR merchant payments (SPEC-002) were both affected. No customer funds were at risk; failures were clean declines rather than duplicate charges.

## Timeline
- 15:20 - Configuration change deployed via the standard pipeline; the value for `downstream_call_timeout_ms` was entered as 300 instead of 3000 due to a unit mismatch in the change ticket.
- 15:26 - Decline rate alert fires.
- 15:33 - Thilina Bandara identifies the recent config deploy as the likely trigger.
- 15:40 - SEV3 declared.
- 15:50 - Configuration rolled back to the previous known-good value.
- 16:05 - Decline rate returns to baseline; incident closed.

## Root Cause
The deployment pipeline for payment-orchestrator configuration changes did not enforce a staging soak test or require a second reviewer to sign off on numeric configuration values. The change ticket specified "300" without units; the engineer applying it assumed milliseconds matched the naming convention used elsewhere, which was incorrect for this particular parameter.

## Resolution
Rolled back to the prior configuration value within 30 minutes of detection. No code change was required.

## Action Items
- Require mandatory peer review and a minimum one-hour staging soak period for all payment-orchestrator configuration changes (owner: Thilina Bandara) - completed 2025-10-22, see RB-001.
- Add config validation guardrails that reject timeout values below a sane floor, e.g. 500ms (owner: Chathura Abeysekara) - completed 2025-11-05.
- Add a post-deploy automated decline-rate check that auto-rolls-back on threshold breach (owner: Priyanka Jayasuriya) - not completed.

This configuration guardrail gap, and its resolution, was discussed at MTG-2026-009 alongside the recurring NorthGate timeout issues, and the peer-review requirement was subsequently extended bank-wide across payments domain services.
